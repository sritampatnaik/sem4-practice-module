## Design Highlights Visible in Screenshots

- **Colors**: Blue (#3b82f6) for primary actions, orange for Math, blue for Physics
- **Spacing**: Consistent padding (16px, 24px, 32px)
- **Typography**: Clear hierarchy with different font sizes
- **Cards**: White backgrounds with subtle shadows
- **Badges**: Rounded pill-shaped status indicators
- **Icons**: Clean, modern icon set
- **Gradients**: Subtle background gradients
