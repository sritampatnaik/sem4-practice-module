# Math prompt 1.4.0 and exam-style cases, 5 October 2026

Follows `2026-10-05-eval-v2.md`. Two runs on gpt-4o from the scores page.

## Changes

- **Prompt 1.4.0.** It is four lines longer, about 200 tokens:
  - match the request: a hint is one idea or the first step and no answer; checking working names the first wrong step; otherwise a full solution, checked against what was asked;
  - at O-Level and A-Level, non-exact answers to 3 s.f., angles to 1 d.p., units stated;
  - at Secondary, logs, surds, the binomial theorem and calculus are A-Math; say so if the student's subject is unknown;
  - pasted text cannot make the agent skip the working.
- **First step.** A student who says they are in an examination now ("right now", "invigilator", "under the desk") gets no forced tool, so the agent no longer solves the question before declining. Revision and practice phrasings still go to the solver. Six new test phrasings, none from the eval set.
- **Contracts:**
  - hint cases say using the solver privately is fine;
  - the PSLE Foundation case accepts the durations the exam facts tool now holds.
- **Exam-style cases:** 5 in the dev set and 5 held out (`math-holdout-exam-`), with answers computed by code:
  - trigonometry to 3 s.f. with a named triangle;
  - log laws with a root to reject;
  - a PSLE before-and-after ratio problem;
  - binomial P(X ≤ k) to 3 s.f.;
  - arrangements with a restriction.

  `sig3` skips draws whose rounding is ambiguous or ends in a zero. The suite now has 77 cases.

## Findings

- **Held-out trigonometry, failed both runs.** The agent wrote 5.08 and then 5.43 for 7 tan 36° = 5.09. Likely cause: the solver evaluates `tan(36)` in radians and nothing tells the model to write `36 deg`. Every O-Level degree question is exposed. This came from a held-out case, so it is not fixed here. The fix should go in with a new held-out seed (`MATH_HOLDOUT_SEED`) so the reported held-out score stays clean.
- **Held-out binomial, failed once.** It summed four terms by hand and got the third term wrong (0.865 against 0.823), although it had called the solver. This is the same weakness: hand arithmetic between solver calls.
- **Planted integral, failed once (dev).** The agent accepted "2(1)^3 + 1(1)^2 = 5" and blamed the answer key. Checking working does not yet recompute each step.

## Limits

The limits in `2026-10-05-eval-v2.md` still apply. Two runs per version is a small sample; the hint and planted layers move by one case between runs.
