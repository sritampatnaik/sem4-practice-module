# Mathematics reference library

Collected 12 September 2026. This is a preparation library across the intended levels; it does not establish approved topic coverage or a selected pilot.

## Collection status

33 catalogue entries: six locally archived MOE curriculum PDFs, seven assessment documents with provisional extracted notes, thirteen unsuccessful downloads with source links retained, and seven link-only entries. PDF validation checks file structure, not the accuracy of extracted claims.

The [manifest](./manifest.json) records publishers, course/cohort labels, source URLs, retrieval status and available checksums. [Assessment notes](./official-assessment/EXTRACTED-NOTES.md) are provisional: the review found incorrect PSLE paper details. Check the official document before using a claim in tutoring or evaluation.

## How to use these references

1. Establish the course, qualification and examination cohort, then review its official curriculum and examination documents.
2. Record topic inclusions, exclusions, prerequisites and the precise source page for each accepted claim.
3. Keep paper specifications, question-specific marking schemes and locally authored tutoring rubrics distinct.
4. Select supplementary topic references after official scope review. Pedagogy guides and OpenStax books do not establish Singapore syllabus coverage.
5. Select a pilot after reviewing the scope map. This folder is not automatically ingested into runtime RAG.

Original publisher rights apply. A publicly accessible PDF or a local reference copy does not establish redistribution or ingestion rights.
