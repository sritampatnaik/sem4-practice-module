# Math solver: degrees, and a fresh held-out draw, 5 October 2026

Follows `2026-10-05-prompt-1.4.md`. Two runs on gpt-4o from the scores page.

## Changes

- **Degrees in the solver.** Before, `tan(36 deg)` was refused ("deg is unknown") and `tan(36)` was read as radians, so 7 tan 36° came back as 54.25. Now:
  - `deg`, `degrees` and `°` after a number or a single letter are converted to radians;
  - a trigonometric call with a bare angle returns a note that it was read as radians;
  - the tool description says to write `36 deg`.

  New test in `tools.test.ts`.
- **Fresh held-out draw.** The previous held-out set found this bug, so the default held-out seed changed from 77031 to 51127. The results below are on cases nobody has looked at.
- **Generator tidy-up.** No behaviour change: the same seed gives the same 77 items.
  - Each template now states its topic and band once.
  - Two unused exports are removed and internal helpers are no longer exported.
  - Section banners are removed, and the binomial sum uses the floating-point mathjs instance.
